VLibrary - электронный помощник с электронными книгами. 

Есть множество книг, с программой или без их всех не перечитать

1 Часть это пользователь открывает, читает книку + делает заметки о ней, сохраняет книгу и заметки в VLibrary как meta BookInfo то, что можно внести автоматом заполняется, что нет, руками...
Производить навигацию по имеющимся книгам
2 Часть поиск по заметкам
3 часть позволяет делать пользователю сквозной поиск по всем книгам ( занесенным в мета или нет и )


Функционал:  
 1 Удобный иллюстрированный каталог электронных книг ( на компьютере или сервере ) + поддержка audio , video  форматов
 2 Введение заметок к читаемым книгам и управление ими, натификации ... 
   Содержание, индексация и быстрй поиск по мыслям и идеям
 3 Выявление дубликатов
 4 Создаение Объединений книг ( ссылок на них) тематических 
   "Изучаем морских животных", "Школьная программа 7 класс"


Как занести книгу в каталог :

1 Указать файл, по нему создастся FileMeta  +  Поля для инфы о книге, Открыть книгу, заполнить BookEntity 
2 Указать папку с кник
Электронный каталог книг  -   ( куча разных файлов источников, Децентрализованное хранение )

1 Создание Import ( Id, Date, Source, TotalFolders, TotalFiles,  List of FileMetaInfo)

- Поиск дубликатов, либо наличия той или иной понравившейся книги
- Создание резервной копии, по источникам, с сохранением определенной структуры, с экспортом заметок и закладок ( S3 ? )
- Самостоятельное добавление Заметок к книге ( в том числе описание ), управление заметками
- Навигация по книгам, которые удалось просмотреть, добавление дополнительного описания
